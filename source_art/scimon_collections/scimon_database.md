## Core balance defaults

| Progress | Wild stage chances | Unlock |
|---|---|---|
| Early | First 100%, middle 0%, final 0% | New game |
| Mid | First 85%, middle 15%, final 0% | Green Stamp earned |
| Late | First 80%, middle 17%, final 3% | Green Stamp + `boss_beaten` story flag |

Stage chances are conditional on the selected encounter branch and a valid pool. The habitat branch is 99.9%; the global migration branch is 0.1%. Migration selects an unlocked stage then a uniform family, so every family is possible after its stage unlock. No single species has a 0.1% encounter chance.

For example, Voltling now has a proposed Baby Voltling → Voltling (Lv 10) → Voltling Prime (Lv 21) chain; Glacibit becomes Baby Glacibit → Glacibit (Lv 10) → Glacibit Prime (Lv 16). Qubit retains its existing three-form chain and existing thresholds. Starter families retain Lv 16 / 32.

The JSON supplies every form’s ID, dex, types, 7 base stats, catch rate, XP yield, ability, learnset, evolution links, exact levels, habitat, wild unlock, sprite paths and atlas coordinates. It also supplies all existing techniques and type matchups.
