# Scimon — all individually separated, named sprites

327 named forms · 109 families · 654 PNGs (327 front + 327 back).

Start with `index.html` to browse or open `sprites/front` and `sprites/back` directly. Every file is one creature in one view. The original grid sheets are not included.

Names and evolution lines: `NAMES_AND_EVOLUTIONS.md`.
Game import and name migration: `instructions.md`.

The game agent must apply the supplied display-name patch; creating this asset pack does not update the live game automatically.
